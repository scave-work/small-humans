# Small Humans

Site perso, en français : musique, cinéma/séries/anime, écriture, tech & IA. En construction.
Direction visuelle : une station spatiale annulaire vue de dessus, fond presque noir, un seul accent bleu.

Site : https://small-humans.github.io/

## Contenu
- `index.html` : la galerie (page d'accueil et musique). Les titres sont dans `musique/titres.json`.
- `cinema/` : le journal de films, séries et anime.
- `tech/` : articles tech & IA (liste dans `tech/articles.json`).
- `archive/` : anciennes maquettes, gardées pour mémoire.
- `v-backend/` : simple redirection pour les anciens liens.
- `OFL.txt` : licence de la police embarquée.
